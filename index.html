Interaktion

Themen-Hex anklicken → ganzer Teilbaum wird hervorgehoben.
Detail-Box anklicken → Herleitungskette zurück zum Kern (nummeriert).
Quelle im Literaturverzeichnis anklicken → alle Zitationsstellen leuchten auf.
Zitat in einer Box anklicken → dito, plus Markierung im Literaturverzeichnis.
Maus über Box → direkte Verbindungen leuchten.
Leere Fläche ziehen = Board verschieben; Cmd/Ctrl + Scrollen oder Pinch = zoomen.
Shift-Klick auf eine Box → Verbindungs-Fokus: die Box und alle direkt verbundenen Boxen (inkl. pinker Querverbindungen) werden hervorgehoben, der Rest abgedunkelt.
Cmd-/Shift-Klick in der Literaturliste → mehrere Quellen auswählen und gemeinsam im Netz anzeigen.
Esc = alles zurücksetzen + Übersicht. Klick auf leere Fläche = nur Hervorhebung aufheben.

Bearbeiten

Der Button «Bearbeiten» oben schaltet in den Bearbeitungsmodus: Klick auf eine Box öffnet den Editor (Text, Farbe, Breite, Löschen), «+ Box» erstellt neue Boxen. Neue Pfeile: Maus über eine Box — an allen vier Seiten erscheinen pinke Kreise; von dort auf die Zielbox ziehen. Pfeil anklicken = Typ ändern oder löschen; mit dem runden Anfasser in der Pfeilmitte lässt sich der Pfeil biegen, um zwischen Boxen hindurchzukommen. Der grüne Griff unten rechts ändert die Boxbreite. Alles wird automatisch gesichert — benannte Stände und JSON-Export/-Import unter «Boards».

Hinweis

Ausgangslage ist die 1:1-Übernahme des Original-PDFs (unter «Boards» jederzeit wiederherstellbar). Zoomen mit den Buttons oder Cmd/Ctrl + Scrollen.
